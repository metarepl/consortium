* consortium

Consortium: a Latin word meaning
"partnership", "association", or "society",
and derives from consors ("shared in property"),
which is in turn derived from con ("together") and sors ("fate").

A consortium is an association of two or more
individuals, companies, organizations, or governments
with the objective of participating in a common activity or pooling their resources
for achieving a common goal.

This system "Consortium" is a coordination layer for interprocess communication of Common Lisp images.
Each image (exempli gratia: StumpWM, Nyxt, Lem, Autolith etc.)
independently registers itself with consortium
creating a mesh of cooperating Lisp processes that can evaluate code
in each other and share symbols — a lightweight Lisp machine on the network without rewriting the world.

* eg configuration

FILE ~/.stumpwmrc
#+begin_src lisp
  (asdf:load-system :metarepl.image.consortium)
  (consortium:register-image :stumpwm)
#+end_src

FILE ~/.nyxtrc
#+begin_src lisp
  (asdf:load-system :metarepl.image.consortium)
  (consortium:register-image :nyxt)
#+end_src

Then from any node:
#+begin_src lisp
  (consortium:nodes)

  ;; evaluation
  (consortium:eval-in :nyxt '(nyxt:current-url))
  (consortium:broadcast '(print "hello from all nodes"))

  ;; symbol sharing
  (consortium:import-remote-symbols :nyxt) ;; from one node
  (consortium:sync-all)  ;; from all nodes

  ;; unification
  (consortium:broadcast '(consortium:sync-all)) ;; interconnect all nodes to all nodes

#+end_src

* eg configuration minimal

FILE ~/.stumpwmrc
#+begin_src lisp
  (asdf:load-system :micros)
  (asdf:load-system :metarepl.image.consortium)
  (consortium/minimal:register "stumpwm" 40001)
#+end_src

FILE ~/.nyxtrc
#+begin_src lisp
  (asdf:load-system :micros)
  (asdf:load-system :metarepl.image.consortium)
  (consortium/minimal:register "nyxt" 40002)
#+end_src

From either image:
#+begin_src lisp
  (consortium/minimal:nodes)
  ;; => ((:NAME "stumpwm" :PORT 40001) (:NAME "nyxt" :PORT 40002))

  (consortium/minimal:eval-in "nyxt" '(+ 1 1))
  ;; => 2

  (consortium/minimal:eval-in "stumpwm" '(stumpwm:current-window))

#+end_src
