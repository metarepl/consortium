* lisp-mash

The lisp-mash system is a coordination layer for interprocess communication of Common Lisp images.
Each image (eg. StumpWM, Nyxt, Lem, Autolith etc.)
independently registers itself with lisp-mash
creating a mesh of cooperating Lisp processes that can evaluate code
in each other and share symbols — a lightweight Lisp machine on the network without rewriting the world.

* eg configuration

FILE ~/.stumpwmrc
#+begin_src lisp
  (asdf:load-system :metarepl.image.lisp-mash)
  (lisp-mash:register-image :stumpwm)
#+end_src

FILE ~/.nyxtrc
#+begin_src lisp
  (asdf:load-system :metarepl.image.lisp-mash)
  (lisp-mash:register-image :nyxt)
#+end_src

Then from any node:
#+begin_src lisp
  (lisp-mash:nodes)

  ;; evaluation
  (lisp-mash:eval-in :nyxt '(nyxt:current-url))
  (lisp-mash:broadcast '(print "hello from all nodes"))

  ;; symbol sharing
  (lisp-mash:import-remote-symbols :nyxt) ;; from one node
  (lisp-mash:sync-all)  ;; from all nodes

  ;; unification
  (lisp-mash:broadcast '(lisp-mash:sync-all)) ;; interconnect all nodes to all nodes

#+end_src

* eg configuration minimal

FILE ~/.stumpwmrc
#+begin_src lisp
  (asdf:load-system :micros)
  (asdf:load-system :metarepl.image.lisp-mash)
  (lisp-mash/minimal:register "stumpwm" 40001)
#+end_src

FILE ~/.nyxtrc
#+begin_src lisp
  (asdf:load-system :micros)
  (asdf:load-system :metarepl.image.lisp-mash)
  (lisp-mash/minimal:register "nyxt" 40002)
#+end_src

From either image:
#+begin_src lisp
  (lisp-mash/minimal:nodes)
  ;; => ((:NAME "stumpwm" :PORT 40001) (:NAME "nyxt" :PORT 40002))

  (lisp-mash/minimal:eval-in "nyxt" '(+ 1 1))
  ;; => 2

  (lisp-mash/minimal:eval-in "stumpwm" '(stumpwm:current-window))

#+end_src
